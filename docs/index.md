# The Knowledge Base

Welcome to the personal knowledge base for **Iliyas Khan** (`khaneliyas01`).

This site is a living documentation hub. It captures **everything about us** —
every project, every repo, the tools we use, the way we work — **except
secrets**. No tokens, no keys, no credentials, no private data ever lands here.

## The rules of this site

1. **No secrets. Ever.** If a fact is secret, it does not belong here.
2. **One page per project.** New repos get a page; changed repos get updated pages.
3. **Written by the `docs` agent.** Every opencode task ends by delegating to the
   `docs` subagent, which records the outcome here.
4. **Public.** Anyone can read it. Write accordingly.
